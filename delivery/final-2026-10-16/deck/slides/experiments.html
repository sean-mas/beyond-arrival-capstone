One change per run, after a control run that shows how much is chance

The method matters more than any single result: one change per run, and a control run first, because the same setup run twice already flips a few answers. The pattern across seven experiments: a prompt rule only worked when it changed the shape of the reply. When the model had to know something the cards did not say, no rule helped; writing the fact into the card did.
